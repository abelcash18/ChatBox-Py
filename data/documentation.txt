Installation and Setup:
- Python 3.8 or higher is required
- Install all dependencies from requirements.txt using: pip install -r requirements.txt
- Create a virtual environment for isolation: python -m venv .venv
- Activate the virtual environment before running the application

Configuration:
The application uses FastAPI for the backend server. Default settings:
- Server runs on http://127.0.0.1:8000
- Frontend served at http://127.0.0.1:8000
- Chat API endpoint: POST /api/chat
- Documents stored in the data/ directory

Using the Chatbot:
1. Open the web interface in your browser
2. Type your question in the input field
3. Press Enter or click Send button
4. The chatbot will process your question and return:
   - An answer generated by the LLM
   - Retrieved context from your documents
   - Source information for transparency

Understanding Retrieved Context:
The "Retrieved Context" section shows:
- Score: Relevance score (higher is better, 0.0-1.0 range)
- Source: File name where the content came from
- Content: Excerpt from the document that was matched

Document Management:
To add documents for the chatbot to reference:
1. Create .txt files with your content
2. Place them in the data/ folder
3. Restart the chatbot application
4. The system will automatically index and embed the documents
5. Future queries will search through these documents

Best Practices:
- Use clear, well-structured text files
- Each file should focus on a specific topic
- Include headings and sections for better retrieval
- Keep file sizes reasonable (avoid very large files)
- Use descriptive file names

Performance Tips:
- The first startup after adding documents may take longer for indexing
- More documents mean more context available but slower search
- Optimal performance with 50-500 moderately-sized text files

Troubleshooting:
- If no context is retrieved, ensure .txt files are in the data/ directory
- Restart the application after adding new documents
- Check that your questions are related to document content
- Review the retrieved context score to understand relevance
